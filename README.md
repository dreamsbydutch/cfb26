# cfb26

A React app built with TanStack Start and Convex.

## Run locally

1. Copy `.env.example` to `.env.local`.
2. Set `VITE_CONVEX_URL` to the Convex deployment URL.
3. Install dependencies and start the app:

```bash
npm install
npm run dev
```

The starter includes the Convex backend in `convex/`. Add queries and mutations there as the product takes shape.
